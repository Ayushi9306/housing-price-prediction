# Housing Price Prediction Using Linear Regression

CS 746 — Perspectives to Data Science  
Student — Ayushi

This project explores whether adding bedroom count improves housing
price predictions compared with using house area alone.

I plan to train both models on a Kaggle housing dataset and compare
them on the same test set using mean squared error (MSE) and R².

Current status — The starter Python script is available in this repository. Testing on the Kaggle housing dataset and reporting the results are still pending.
